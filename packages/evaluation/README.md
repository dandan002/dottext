# Evaluation

Implement evaluation dimensions and acceptance evidence from [pilot](../../docs/pilot.md): coverage, retrieval, attribution, factual support, numerical integrity, editorial quality, privacy, and operations. Record expected passage identities alongside corpus/version/model/prompt/provider, actual outputs, costs, and reviewer findings.

Use deterministic checks for citation identity, units/periods, permissions, reservation concurrency, replay, and schedule identity. Semantic support and research usefulness require human review; sampled model judges supplement it and count against budget.

Start with known evidence for Chile/Colombia and adversarial stale-date, stakeholder-scope, disagreement, and unsupported-question cases. Add two-workspace access, Codelco anchor coverage, correction preservation, concurrent budget, and New York DST/retry checks as those features arrive. Set quantitative thresholds from measured samples rather than inventing success targets.
