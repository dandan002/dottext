- [Chile](chile/README.md): Codelco/anchor coverage and source revisions.
- [Colombia](colombia/README.md): fiscal financing, flows, divided vote.

For each fixture record its ID, country, source/access policy, original URL, document/revision/passage IDs, publication/modification/collection times, text completeness, expected supporting passages, distinctions to preserve, expected gaps, and review status. Pin corpus versions and annotate human judgments. Do not embed licensed text without permission.
