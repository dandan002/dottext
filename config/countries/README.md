# Country profiles

Build editable, versioned country profiles defining persistent drivers, institutions, entities, and coverage checks. Initial profiles are [Chile](chile.md) and [Colombia](colombia.md). Brazil is a future candidate; Poland and Turkey are later candidates, with no pilot coverage claim.

Hourly collection remains broad. Before briefing selection, check each profile anchor for significant developments in the requested period plus relevant dated context. Persist what was searched and whether evidence was unavailable, unchanged, or materially new. Anchor checks must distinguish collection failure from absent developments.

Follows refine priorities without suppressing major developments. Allocate social/political coverage by significance and evidence, not publication volume. Version profile edits and invalidate relevant cache identities. Validate Codelco coverage amid unrelated news and Colombian financing/institutional-flow evidence.
