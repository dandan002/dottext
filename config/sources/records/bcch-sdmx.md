# bcch-sdmx — Banco Central de Chile SDMX files (IMF National Summary Data Page)

| Field | Value |
| --- | --- |
| Source ID / publisher | `bcch-sdmx` / Banco Central de Chile, distributing its own statistics and INE's and DIPRES's for the IMF data standard |
| Country / language | Chile / codes and English category names |
| Status | **Validating** — live collection succeeded 2026-11-17; no credential needed |
| Discovery endpoint and method | The [National Summary Data Page](https://si3.bcentral.cl/estadisticas/diario1/aplicaciones/NSDP/nsdp.html) links 28 categories at `https://si3.bcentral.cl/SieteSdmx/SieteSdmx.ashx?SDMXCategory=SDMX_<CODE>`. Producers per that page: BCCh (national accounts, sectoral balance sheets, monetary surveys, financial soundness, debt securities, interest rates, exchange rates, reserves, reserves template, trade, balance of payments, international investment position, external debt), INE (CPI, PPI, production, employment, unemployment, wages, population), DIPRES (general and central government operations and debt), Bolsa de Santiago (share price index). Ten are configured in [`bcch-sdmx-categories.json`](../bcch-sdmx-categories.json). |
| Article and attachment extraction | n/a — SDMX 2.1 StructureSpecificData, IMF `ECOFIN_DSD` 1.0. Series attributes FREQ, DATA_DOMAIN, REF_AREA, INDICATOR, COUNTERPART_AREA, UNIT_MULT, TIME_FORMAT, optional BASE_PER; observations TIME_PERIOD, OBS_VALUE, OBS_STATUS. Series ID = category + domain + area + indicator + counterpart + frequency (+ base period, so a rebased index is a new series). |
| Publication/modification/event time parsing | Periods `YYYY-MM` or `YYYY-Qn`; release times not provided. Each response returns the full history from 2010, so every run can detect revisions. |
| First-seen/collection handling | Vintages by `retrievedAt`; changed values stored as new vintages. Statistics runs look back two years of reference periods by default because releases lag periods. |
| Actual history range and gaps | From 2010-01 (monthly) / 2010-Q1 (quarterly); some indicators discontinued (deposit rate `FID_PA` ended 2017-07, 1-month forward ended 2023-10). |
| Access/retention terms and supporting references | [BCCh terms of use](https://www.bcentral.cl/en/terms-of-use) (unaltered use with citation); BCCh's statistics terms allow free consultation, reproduction, publication and adaptation citing the Bank or the original source. INE and DIPRES categories are attributed to them via `producer`. |
| Permitted full text / excerpt / metadata / snapshots | Numerical data. |
| Duplicate and correction behavior | Vintage comparison per (series, period). Overlaps with BDE series (CPI, exchange rate) are kept as separate sources; reconcile by series, not by merging. |
| Failure, retry, and rate behavior | `si3.bcentral.cl` is not behind the Incapsula challenge that guards www.bcentral.cl. Responses 0.4–15 s; balance of payments is 2.7 MB (375 series). 3 s spacing, 15 requests/run. **Publisher quirk:** the exchange rate declares `UNIT_MULT=1` although values (~982) are CLP per USD; the curated config corrects the multiplier to 0 and labels the series as a period average (IMF `ENDA`; values carry 21-day-average decimals). Unit labels otherwise follow IMF indicator suffixes (`_USD`, `_XDC` = CLP, `_IX`, `_PA`); `_SA_` marks seasonally adjusted series; everything else stays `unknown`. |
| Validation fixtures and run evidence | `packages/connectors/test/fixtures/bcch-sdmx/category.xml` (synthetic values). Live run 2026-11-17: 10 requests, 3,244 observations, status `succeeded`; latest CPI 114.13 (2026-10, base 2023), CLP/USD 982.28 (October average), overnight interbank rate 4.5, reserves USD 53,638.8 million, exports USD 10,287.3 million, central government debt USD 164,717.7 million (2026-Q2). |
| Validation date / owner | 2026-11-17 / owner pending |
| Activation decision | Ready to activate on owner confirmation. Gives Chile macro coverage without the BDE token; daily series (policy rate, observed dollar, Imacec) still need `bcch-bde`. |
