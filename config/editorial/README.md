# Editorial configuration

Apply [shared editorial requirements](../../docs/editorial.md) to all generated English outputs. Original-language source text stays unchanged. The AP Stylebook is the default; consult the current authorized edition for uncertain rules.

Maintain [market-notation exceptions](market-notation.md) as explicit house decisions. Version editorial prompts/rules and record an AP pass in final editing. Evidence fidelity, quotation meaning, and numerical precision take precedence over style.
