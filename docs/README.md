# Shared requirements

These documents distribute the supplied Draft 0.1 specification by responsibility. They are build requirements, not evidence that features already exist. Component READMEs link back here for cross-cutting rules.

| Document | Purpose |
| --- | --- |
| [Product](product.md) | Outcomes, scope, portal behavior, feedback |
| [Editorial](editorial.md) | AP style, attribution, analyst roles, quotations |
| [Architecture](architecture.md) | Services, API boundaries, working defaults, security |
| [Data and evidence](data.md) | Records, timestamps, revisions, citations, caches |
| [Operations](operations.md) | Collection, schedules, budget, recovery, telemetry |
| [Delivery](delivery.md) | Ordered implementation stages and exit evidence |
| [Decisions](decisions.md) | Unresolved choices and technical references |
| [Pilot](pilot.md) | Acceptance criteria, evaluation cases, human review |

Country anchors, source onboarding, and editorial exceptions live under [config](../config/README.md). Executable evaluations belong in [packages/evaluation](../packages/evaluation/README.md); evidence files belong in [fixtures](../fixtures/README.md).
